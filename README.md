# StudyFlow — Бюро обучения

Учебное Flask-приложение: четыре курса, планирование задач, фокус-сессии и питомец.
Светлый интерфейс сочетает спокойную типографику и элементы управления с геометрией советского модернизма. Есть альтернативная тёмная тема, мобильная компоновка и поддержка уменьшения анимации.

## Запуск

Нужен Python 3.10 или новее. Из папки проекта:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py
```

Открой http://127.0.0.1:5000. На macOS/Linux используй `.venv/bin/python`.

## Возможности

- SQLite сохраняет профиль, задачи, прогресс и питомца между перезапусками.
- Прогресс каждого урока и курса; кнопка продолжения со следующего непройденного урока.
- Личные заметки к урокам с предупреждением о несохранённых изменениях.
- Закладки, поиск по содержимому уроков и фильтры статуса.
- Настраиваемая дневная цель от 5 до 480 минут.
- История за семь дней и серия дней занятий (граница дня — Москва, UTC+3).
- Редактирование задач, приоритеты, сроки, отметки просрочки, поиск и фильтр.
- Перемещение задач мышью или доступным с клавиатуры списком колонок.
- Таймер сохраняет состояние в браузере и считает время по абсолютной отметке, включая фоновые вкладки. Неудачную запись завершённой сессии можно повторить.
- Экспорт профиля в JSON для личного архива (обратный импорт пока не реализован).
- Достижения остаются открытыми. Повторное завершение урока, задачи или отправка одной и той же сессии таймера не начисляют награды повторно.

## Данные и развёртывание

По умолчанию база и автоматически созданный ключ сессий находятся в `instance/`, исключённой из Git. Сохраняй эту папку целиком: без прежнего ключа cookie существующих профилей перестанут распознаваться. Можно задать `SECRET_KEY` и `STUDYFLOW_DATA_DIR` переменными окружения. Отладочный режим выключен; для локальной разработки включается через `FLASK_DEBUG=1`.

Профиль анонимный, привязан к cookie браузера; это не система учётных записей и не синхронизация между устройствами. Удаление cookie создаёт новый профиль. Данные старой версии хранились только в памяти и автоматически восстановлены быть не могут.

Для размещения используй постоянный диск и направь `STUDYFLOW_DATA_DIR` на него. Существующий `render.yaml` оставлен с бесплатным тарифом: **локальная SQLite на временной файловой системе хостинга не обеспечивает сохранность после пересоздания сервиса**. Для такого размещения сначала настрой постоянный диск либо адаптируй хранилище к внешней БД. Не запускай несколько экземпляров на разных дисках с ожиданием общей базы.

Статистика уроков использует плановую длительность, а не измерение времени чтения. Таймер предназначен для личного учёта: клиент сообщает завершение сессии; это не защищённая от подделки система рейтинга. Автозапуск следующего интервала и уведомления при закрытом браузере не реализованы.

## Проверка

```powershell
.venv\Scripts\python.exe -m unittest -v test_app
```

Восемь тестов проверяют страницы и ресурсы, изоляцию профилей, чтение сохранённых данных новым клиентом, конкурентные запросы, заметки/закладки, задачи, таймер и ошибочные входные данные. Тесты используют отдельную временную базу.

Структура: `app.py` — маршруты, валидация и SQLite; `content.py` — курсы и достижения; `templates/` — Jinja; `static/js/` — интерфейс; `static/css/design.css` — новая визуальная тема поверх базовых стилей.
