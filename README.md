# 🐣 StudyFlow

Веб-приложение для обучения программированию (в VS Code) с:
- 📚 4 курсами (VS Code, Python, HTML/CSS, Git)
- 📋 Канбан-доской (drag & drop)
- ⏱ Таймером Помодоро
- 🐣 Питомцем, который растёт от твоей активности

## Локальный запуск

```bash
pip install -r requirements.txt
python app.py
